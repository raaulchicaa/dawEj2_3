#  Uso avanzado de GitHub – Despliegue de Aplicaciones Web

## 📘 Descripción del proyecto
Este repositorio forma parte de la **Unidad 2** de la asignatura **Despliegue de Aplicaciones Web** del ciclo formativo **DAW**.

En este proyecto se trabajan los ejercicios **2_3 y 2_4**, centrados en el uso de **Git y GitHub**, el manejo de **ramas**, repositorios remotos y la documentación mediante **Markdown**.

## 🌿 Estructura de ramas y trabajo realizado
En este proyecto se ha trabajado con varias ramas y entornos:

### 🔹 Ramas utilizadas
- **main**: rama principal del proyecto
- **version1**: rama de desarrollo

### 🔹 Repositorios remotos
- **origin/main**
- **origin/version1**

El flujo de trabajo ha consistido en:
1. Trabajo en **local**
2. Sincronización con **GitHub**
3. Trabajo y pruebas desde una **máquina EC2 de Amazon**
4. Uso de `commit`, `push` y `pull` para mantener el repositorio actualizado

> Este proceso permite simular un entorno real de despliegue y control de versiones.
